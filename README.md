# Реплика — команда NEXUS

Android-приложение для Nuclear IT Hack: локальная расшифровка аудиозаписей с говорящими, временными метками и экспортом JSON.

**Версия 0.6.1:** выбранный тёмный дизайн, новый знак из двух сообщений — голубого и сиреневого, компактная карточка файла, фиксированная панель действий, копирование текста и прослушивание с паузой и продолжением. Повторная обработка скрыта в параметрах, технические показатели доступны через «О записи». Алгоритмы, модели и формат JSON сохранены от 0.4. [Оформление и проверки](docs/DESIGN_RESULTS.md), [все проверки](docs/TEST_RESULTS.md).

В версии 0.4 парный запуск диалога длительностью 169.01 с ускорился с 290.63 до 261.20 с; 45 ASR-текстов, 654 региона на 16 записях и 7 итоговых расшифровок совпали с 0.3. Эти широкие регрессии и замеры выполнены на APK 0.4, а не повторно на 0.6. [Ускорение и методика](docs/SPEED_RESULTS.md), [шумная речь](docs/NOISE_RESULTS.md). Пользователь предоставил видео проверки на Samsung Galaxy S10; подробности и пределы проверки — [PHONE_TEST](docs/PHONE_TEST.md). Текущий полный APK — около 906 МиБ.

Пакет передачи, локальный Git-репозиторий и оставшиеся действия: [SUBMISSION](docs/SUBMISSION.md), [готовность по условиям](docs/READINESS.md).

## Возможности

- Выбор локального аудиофайла через системный диалог Android.
- WAV PCM 8/16/24/32 bit и float32; MP3/M4A и другие форматы, которые декодирует Android MediaCodec.
- Приведение к моно 16 кГц, автоматическая диаризация, транскрибация и пунктуация локальной LLM.
- Говорящие с постоянными ID в пределах записи, начало и конец реплик в миллисекундах.
- Просмотр, прослушивание фрагментов, экспорт JSON в выбранное пользователем место.
- Прогресс, отмена между этапами модели, восстановление последнего завершённого результата.
- Все веса входят в полный APK. Разрешение `INTERNET` отсутствует.

## Установка и проверка на телефоне

Нужен Android 8.0+ с ABI `arm64-v8a`. Реальные требования к RAM и скорость ещё нужно измерить. Предварительно освободите около 4 ГБ для APK, распакованных моделей и записи.

1. Скачайте APK по ссылке выше и перенесите его на телефон и разрешите установку из выбранного источника.
2. Установите APK. Отладочная подпись подходит для хакатонного прототипа, не для публикации в магазине.
3. Включите авиарежим. Откройте приложение и выберите **локальный**, уже скачанный аудиофайл.
4. Выберите язык и нажмите «Расшифровать запись».
5. Первый запуск копирует и проверяет модели. Оставайтесь в приложении до завершения; экран сохраняется включённым.
6. Нажмите ▶ рядом с репликой для прослушивания; повторное нажатие ставит на паузу. Кнопка «Сохранить JSON» сохраняет результат.

Ограничение первой версии: до 15 минут и 256 МБ на входной файл. Назначение говорящих автоматическое, заранее заданного числа участников нет. Одновременная речь пока не разделяется на отдельные аудиодорожки.

## Локальный запуск на этом Mac

После подготовки виртуального устройства Android 15 приложение открывается отдельным окном:

```sh
./scripts/run-emulator.sh
```

Скрипт использует локальный SDK в `.tools/android-sdk` и устройство `NeuroScribe_API_35` в `.tools/avd`, устанавливает APK, если приложение ещё не установлено, и копирует короткий пример в Android: `Download/neuroscribe-test-russian.wav`. Его можно выбрать кнопкой «Выбрать аудио». После пересборки APK обновите установленную версию командой `.tools/android-sdk/platform-tools/adb -s emulator-5566 install -r artifacts/neuroscribe-debug.apk`.

Эмулятор подходит для просмотра интерфейса и проверки сценариев. Скорость и расход памяти на физическом телефоне нужно измерять отдельно.

## Сборка

Требуются JDK 17, Android SDK 35, Build Tools 35.0.0, NDK 27.2.12479018, CMake 3.22.1, Gradle 8.13 и Python 3.10+. На этом Mac локальные инструменты находятся в `.tools/` и не меняют системные установки.

```sh
# На macOS SDK можно подготовить локально: python3 scripts/prepare_sdk.py
python3 scripts/prepare_dependencies.py
python3 scripts/prepare_models.py
./scripts/build.sh
```

Скрипт сборки запускает unit-тесты, Android Lint и собирает debug APK. Все шесть моделей обязательны: сборка поставки прекращается, если пакет не готов. Зависимости и веса скачиваются **при подготовке на компьютере**; приложение ничего не скачивает и не обращается к серверу.

Для обычной Android Studio укажите SDK в `local.properties`, откройте корень проекта и используйте JDK 17. Папки `.tools`, `third_party/llama.cpp`, веса и AAR не коммитятся: их восстанавливают скрипты с закреплёнными версиями.

## Выходной контракт

```json
{
  "transcript": [
    {
      "speaker_id": "speaker_1",
      "start_ms": 1250,
      "end_ms": 4380,
      "text": "Добрый день!"
    }
  ]
}
```

Экспорт содержит только этот контракт. Метрики обработки отображаются отдельно в интерфейсе. При отсутствии речи экспортируется пустой массив; реплики не выдумываются.
