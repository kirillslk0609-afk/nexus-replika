# Тестовые записи команды

Эти записи синтезированы средствами macOS и предназначены для первичной проверки импорта, запуска моделей и экспорта. Они не заменяют тесты на разговорах живых людей.

- `russian.wav`: 10,28 с, голос Milena, mono PCM16 16 кГц. Точный исходный текст в `russian-reference.txt`. На Mac Whisper пропустил предлог «в» перед словом «файл».
- `two-voices-synthetic.wav`: 15,65 с, голоса Samantha и Daniel, 4 чередующиеся реплики. Исходный текст и интервалы синтезированных фрагментов в `two-voices-synthetic-reference.json`. Базовая диаризация ошибается на этой записи: выделяет 3 голоса вместо 2. Это сохранённый отрицательный тест.

В приложение не встроены ни эти записи, ни эталонные расшифровки. При выборе любого файла оно запускает реальные модели; эталоны используются только внешним скриптом оценки.

Для WER после экспорта результата с телефона:

```sh
python3 scripts/evaluate.py samples/russian-reference.txt /path/to/export.json
```
