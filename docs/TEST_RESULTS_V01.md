Android 15 / API 35, arm64-v8a, 4 ГБ RAM, Android Emulator 37.2.13 на Mac. Включён авиарежим; у основного APK нет разрешения INTERNET.

Папка распакованных моделей была удалена из рабочего пути тестом: все шесть файлов восстановились **из APK без сети за 2.460 с**. ## Сравнение и нерешённые ошибки

Порог кластеризации изменён с 0.5 на 0.7 после сравнения нескольких файлов. На Mac это исправило синтетический контроль с 3 до 2 голосов и китайский с 5 до 4; более высокий порог объединял разных людей. Сравнивались также TitaNet/WeSpeaker: универсального улучшения не получено, поэтому в APK сохранён CAMPPlus. Подробности: `artifacts/diarization-*.json`; воспроизведение — `scripts/benchmark_diarization.py`.

В Android после добавления антиалиасингового фильтра и ограничения генерации LLM первый естественный разговор изменился с **13 до 8** найденных голосов (ожидается 2), время — 283,182 → 248,240 с. Второй — **6 → 8** голосов (ухудшение), время 249,405 → 219,484 с. Менялись два компонента одновременно, поэтому ускорение нельзя приписать только одному. Исходные отчёты сохранены в `artifacts/test-results/before-resampler/`. Фильтр оставлен ради корректного преобразования частоты; обещать улучшение диаризации на любой записи нельзя.

На естественной речи остаются дробление голосов и реплик, ошибочные слова и смешение перекрывающейся речи. Это главный риск качества перед проверкой жюри. Нет достаточной ручной разметки для общего WER/DER.

## Демонстрация через интерфейс

На текущем APK в авиарежиме выполнено: выбор английского WAV → язык → обработка → два говорящих/четыре реплики → запуск прослушивания фрагмента → сохранение JSON системным диалогом. Для 16 с аудио показано **4,649 с / RTF 0,291**, четыре вызова LLM. Это отдельный обычный запуск приложения; время не смешивается с инструментальными измерениями выше. Экспорт совпал с внутренним результатом, содержит только заданные поля.

Непрерывная запись экрана: `artifacts/demo/neuroscribe-emulator-demo.mp4`. Системный screenrecord не записывает звук, поэтому ролик показывает нажатие воспроизведения, но не служит доказательством слышимого аудио. Результат/экспорт/кадр: `artifacts/demo/`.
