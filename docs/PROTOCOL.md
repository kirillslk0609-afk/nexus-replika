# Контракт импорта и экспорта

Задание — локальная расшифровка, поэтому раздел акустической передачи из общего шаблона организаторов здесь неприменим. Между устройствами приложение ничего не передаёт.

## Вход

Системный выбор локального файла Android (Storage Access Framework). WAV PCM 8/16/24/32 bit и float32; MP3/M4A и другие контейнеры — через системные декодеры Android. Выбранный файл копируется в приватное хранилище. Если копирование не удалось или отменено, предыдущая запись остаётся доступной.

Ограничения текущей сборки: 256 МБ и 15 минут. Они заданы командой, а не PDF; допустимость для проверочных записей надо подтвердить у организаторов.

## Выход

```json
{
  "transcript": [
    {
      "speaker_id": "speaker_1",
      "start_ms": 1250,
      "end_ms": 4380,
      "text": "Добрый день!"
    }
  ]
}
```

- Корневой объект содержит только `transcript`.
- ID — строка; времена — целые миллисекунды от начала исходного файла; текст — UTF-8.
- Реплики экспортируются по времени начала. При перекрывающейся речи интервалы могут пересекаться.
- ID присваиваются по первому появлению участника в конкретной записи; между разными файлами идентичность не сохраняется.
- Для тишины: `{"transcript": []}`. Невалидный файл приводит к сообщению об ошибке, не к успешному пустому результату.
- Сохранение — через системный диалог создания документа. Пользователь выбирает место и имя.
- Диагностические поля, скорость, число вызовов LLM и результаты тестов в экспорт не добавляются.

## Повторный запуск и ошибки

Завершённый результат сохраняется локально и восстанавливается после закрытия приложения. Незавершённый результат не выдаётся за готовый. Отмена проверяется при подготовке, чтении и между нативными этапами/репликами; текущий нативный вызов может завершаться с задержкой.

Интернет-разрешения у приложения нет. На момент проверки все модели уже находятся в APK и после первой подготовки — в приватной папке приложения.
