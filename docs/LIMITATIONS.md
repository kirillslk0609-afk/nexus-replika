# Ограничения версии 0.6.1

- Работоспособность нативного инференса, пик RAM, нагрев, WER и RTF на реальном Android пока не измерены. Успешная компиляция не является проверкой качества.
- Поддерживается только `arm64-v8a`, Android API 26+. 32-битные телефоны и x86-эмуляторы не входят в сборку.
- Максимум 15 минут / 256 МБ входного файла. Все модели внутри APK увеличивают его размер и требуют дополнительного места при первом запуске.
- Одновременная речь не разделяется на независимые источники. Возможно смешение текста в перекрывающихся репликах.
- Ошибка «8 голосов вместо 2» на двух исходных разговорах исправляется новым алгоритмом 0.2; полный набор результатов см. DIARIZATION_RESULTS.md. Это не гарантия правильных ID на каждой реплике или новых записях. На длинных записях обработка занимает минуты.
- Короткие ответы, похожие голоса, шум и музыка могут ухудшать диаризацию и ASR. Число участников определяется эвристически, не гарантируется.
- Временные метки соответствуют сегментации аудио. Пословного forced alignment нет; длинные сегменты режутся на части по 25 секунд.
- В версии 0.3 Whisper base заменён на многоязычный Whisper small INT8 ради качества шумной речи. APK стал больше, инференс медленнее; скорость и память нужно измерить на физическом телефоне. Отдельные фразы могут распознаваться хуже, даже если средний WER улучшился.
- Пунктуация маленькой LLM может быть слабой. Её текст принимается только при совпадении последовательности слов/чисел с ASR; это не исправляет ошибки исходного распознавания.
- Антиалиасинговый FIR-фильтр реализован; шумоподавление и разделение источников не реализованы.
- Отмена ожидает завершения текущего нативного вызова. Фоновая работа с уведомлением и возобновлением после остановки процесса не реализована.
- Запись с микрофона, ручной редактор, несколько сохранённых сессий, аппаратное GPU/NPU-ускорение не реализованы.
- Совместимость MP3/M4A зависит от декодеров устройства; WAV PCM читается собственным кодом.
- Обработка в реальном времени не заявляется.

- Подавление групп с материалом меньше max(2,5 с; 5% суммарного материала) может объединить редкого участника с другим человеком, особенно при коротких ответах. Если чистой речи нет, признаки ненадёжны. Silhouette score — эвристика, а не вероятность правильного числа людей.
- Признаки из перекрывающихся окон коррелируют; независимая выборка для общей оценки качества пока мала. Проверка по раздельным каналам — ограниченный автоматический показатель, не ручной DER.

- Ускорение 0.4 зависит от кодека и длительности исходного аудио, числа точных повторов реплик и продолжений LLM, отклоняемых итоговым фильтром. Асинхронный путь действует для форматов MediaCodec, например MP3/AAC. Чтение WAV не менялось. Пользовательская видеопроверка на Samsung Galaxy S10 описана в [PHONE_TEST](PHONE_TEST.md); ускорение на телефоне не измерено. Для WAV без повторов и отклонений ускорение не гарантируется. Коэффициент ускорения LLM нельзя переносить на всё приложение. Кеш ограничен одной записью и 64 точными текстовыми ключами; все модели по-прежнему работают локально.
