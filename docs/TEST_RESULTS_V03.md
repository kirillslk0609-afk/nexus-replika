# Проверки версии 0.3.0 — 7 ноября 2026

**22/22 JVM-теста и 16/16 Android-тестов прошли.** Финальный полный прогон завершился без ошибок. Android Lint: 0 ошибок, 15 предупреждений. Включены 45 вариантов для парного ASR-сравнения, 16 записей диаризации, реальные ASR/LLM, WAV/MP3/AAC, отмена, поворот экрана, повреждённые файлы, тишина, паузы и восстановление моделей без сети.

На всех 16 записях ID и времена 654 регионов точно совпали с 0.2. [Проверка диаризации](DIARIZATION_RESULTS.md).

На 36 шумных случаях ASR WER снизился с 21.51% до 9.86%; чистые контроли: 6.73% → 5.29%. Это девять исходных записей с пятью условиями, не 45 разных людей. Присутствуют отдельные ухудшившиеся случаи, все перечислены в [отчёте по шуму](NOISE_RESULTS.md).

## Офлайн, сборка и поставка

Шесть файлов моделей восстановлены из APK в авиарежиме за 9.258 с. Повреждение файла той же длины обнаруживается и исправляется. INTERNET отсутствует. Проверены SHA-256 всех весов внутри APK, подпись v2 и выравнивание zip/ELF 16 КБ. APK: 904.5 МиБ; новая модель увеличила размер и время ASR.

Чистая сборка из отдельной копии исходников прошла с 22 JVM-тестами. Закреплённые зависимости были скачаны ранее; это не побайтовая воспроизводимость и не новая установка с загрузкой всего из сети.

Логи и измерения: `android-instrumentation.txt`, `test-results/summary.json`, `noise-comparison.json`, `diarization-regression.json`, `apk-verification.json`, `reproduction-check.json`. История 0.1/0.2: TEST_RESULTS_V01.md, TEST_RESULTS_V02.md и папки before-* в test-results.
