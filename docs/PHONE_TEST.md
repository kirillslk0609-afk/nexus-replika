# Видеопроверка на физическом телефоне — 8 ноября 2026

Устройство: Samsung Galaxy S10 — по сообщению участника команды. Точный индекс, процессор, RAM и версия Android не установлены. Исходный ролик предоставлен пользователем; хеш установленного APK в нём не показан.

Материал: локальный MP3 Kai Angel — Are You Happy. Музыка с вокалом использована как стресс-тест, а не как эталон качества распознавания разговоров.

В видео видны этап распознавания, готовая расшифровка с временными метками и ID «Говорящий 1» / «Говорящий 2», воспроизведение фрагмента и системный диалог сохранения JSON. На кадрах обработки и результата показан авиарежим без значка Wi-Fi; в начале ролика Wi-Fi включён. Непрерывный сетевой аудит не проводился. Отсутствие INTERNET и включение моделей в поставляемый APK проверены отдельно упаковщиком.

Ролик смонтирован: 42,47 секунды видео не являются временем обработки. Время, RAM, WER и DER на телефоне не измерены. Число реальных исполнителей не размечено; два ID не доказывают правильность диаризации. На музыкальном материале возможны ошибки текста. Открытие диалога экспорта видно, содержимое сохранённого JSON по этому видео не проверено.

Видеофайл публикуется в релизе как `replica-samsung-s10-check.mp4`. Метрики эмулятора из остальных отчётов нельзя переносить на этот телефон.
