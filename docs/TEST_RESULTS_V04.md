# Проверки версии 0.4.0 — 7 ноября 2026

**24/24 JVM-теста и 19/19 Android-тестов прошли.** Полный финальный прогон завершился без ошибок. Android Lint: 0 ошибок, 15 предупреждений. Все шесть весов остались прежними.

- Восемь входных файлов дали побитово одинаковый PCM после изменения декодера; проверены MP3, AAC/M4A и WAV.
- 45 ASR-результатов на чистом и шумном звуке совпали с 0.3 посимвольно.
- 654 региона на 16 записях совпали по ID и временным границам.
- Семь полных JSON-расшифровок совпали с 0.3, включая пунктуацию; среди них два естественных разговора.
- Парные измерения проверили 16 фрагментов для LLM и два полных процесса.

На парной записи длительностью 169.01 с: 290.63 → 261.20 с. LLM отдельно после прогрева: 34.90 → 30.81 с (1.13×). Это разные измерения; коэффициент LLM нельзя переносить на всё приложение. [Методика, этапы и ограничения](SPEED_RESULTS.md).
