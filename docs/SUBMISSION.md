# Передача решения

## Что передавать

- `artifacts/neuroscribe-debug.apk` — полный APK со всеми моделями.
- `artifacts/neuroscribe-source.zip` — исходники, тесты и документы; большие зависимости восстанавливаются скриптами.
- `artifacts/neuroscribe-git.bundle` — готовый локальный Git-репозиторий, независимый от других проектов на этом компьютере.
- `artifacts/demo/neuroscribe-emulator-demo.mp4` — архивная непрерывная запись Реплики 0.5.0 (предыдущий светлый дизайн) в эмуляторе: выбор WAV, реальная обработка двух говорящих, прослушивание и экспорт JSON. Это не видео физического телефона.
- `artifacts/SHA256SUMS` — контрольные суммы поставки.

## Репозиторий и релиз

Исходники, установка, архитектура, ограничения и результаты проверок: https://github.com/kirillslk0609-afk/nexus-replika

APK, исходный архив, Git bundle и видеодемонстрации: https://github.com/kirillslk0609-afk/nexus-replika/releases/tag/v0.6.1

APK не входит в историю Git из-за размера. Модели полностью упакованы в APK; для самостоятельной сборки их скачивают закреплённые скрипты.

Актуальная видеодемонстрация эмулятора: `replica-offline-check-emulator.mp4`. Пользовательское видео Samsung S10: `replica-samsung-s10-check.mp4`, с оговорками из [PHONE_TEST](PHONE_TEST.md). Архивное видео 0.5 сохраняется только как исторический материал.

Согласно сообщению организаторов: загрузить и отправить материалы до 09:00 8 ноября, после 09:00 не менять код; презентацию можно обновлять до 13:30. Ссылку на репозиторий нужно самостоятельно отправить в форму сдачи. Наличие репозитория не означает отправку формы.

Остаётся отдельно измерить время и память на реальном разговоре и проверить первый запуск на физическом устройстве полностью без сети. Не переносить показатели эмулятора в строку телефона.

## Воспроизведение проверок

```sh
./scripts/build.sh
./scripts/run-emulator.sh
./scripts/run_design_checks.sh emulator-5566
python3 scripts/package_submission.py
# Полный набор регрессий движка при изменении обработки:
# ./scripts/run_android_checks.sh emulator-5566
```

`run_android_checks.sh` предназначен для тестового устройства: устанавливает приложение и тестовый APK, включает авиарежим, меняет текущую запись приложения и проверяет восстановление моделей. Не запускайте его на устройстве с единственными несохранёнными расшифровками.

Тестовый APK и тестовые аудиозаписи не включаются в основной APK. Для обычного использования нужен только `neuroscribe-debug.apk`.

Для обновления интерфейса 0.6 используется `run_design_checks.sh`: 5 целевых тестов, включая реальный инференс. Он сохраняет и восстанавливает пользовательские `current-audio` и `last-result.json` внутри UI-тестов, включает авиарежим. `package_submission.py` допускает сохранение широкого отчёта 0.4 только при совпадении всех исходников обработки, native-библиотек и моделей, наличии текущего отчёта и правильного хеша APK. Это не выдаёт старые 19 тестов за новый прогон.
