# Конфигурация поставки

- `models.lock.json`: URL, размер, SHA-256 загружаемого файла и извлечённой модели.
- `packaged-models.json`: фактический манифест моделей для проверки APK; совпадает с `assets/models/manifest.json`.
- `llama-commit.txt`: закреплённая версия нативного движка.
- `test-fixtures.json`: происхождение, лицензии и контрольные суммы тестовых записей.

Ключи API, серверные адреса и `.env` для работы приложения не требуются. Сеть используется только компьютером разработчика для подготовки зависимостей.
