# Иконка «Реплика»

Создана встроенным инструментом Imagegen; не через CLI/API-ключ. Финальный исходный растр: `artifacts/design/replica-icon.png`; ресурс Android: `app/src/main/res/drawable-nodpi/replica_icon.png`. Адаптивная маска: `mipmap-anydpi-v26/ic_launcher.xml`.

## Промпт

Use case: logo-brand. Asset type: production Android app icon and avatar, square 1024x1024. Create a polished minimalist symbol for a Russian offline speech transcription app called Реплика (do not include any text). Full-bleed solid deep forest green background #123D35, no rounded outer square, no device mockup. Center a single bold warm ivory #F8F4EB speech bubble symbol with three deep green vertical sound-wave slots cut out of it; the middle slot taller, rounded ends. One small muted apricot #DFA77C accent dot integrated near the lower right of the bubble. Friendly, precise, editorial, timeless geometric identity, flat clean vector-like edges, no gradients, no shadows, no 3D, no letters, no watermark. Icon needs excellent legibility at 48px. Keep all foreground artwork inside the central 60% square so Android adaptive circular masks never clip it. Symmetric balanced composition with generous solid green negative space. Output only the finished icon.

Фактический результат — 1254 × 1254 PNG с лёгкой фактурой. Встроен без перерисовки; символ проверен в шапке приложения и в системной адаптивной маске.
