# Результаты

`summary.json` связывает результаты Android-тестов с SHA-256 проверенного APK. `results.csv` содержит время, число голосов и WER только для записей с известным текстом. Пустой WER означает отсутствие разметки, не нулевую ошибку.

`before-resampler/` и `before-diarization-v2/` — предыдущие сборки для сравнения, не финальный результат. `diarization-regression.json` содержит реальные регионы Android; `diarization-audit.json` — число голосов и ограниченное согласие с раздельными каналами. Это не ручной DER. Полная интерпретация и ограничения: `docs/TEST_RESULTS.md`. Устройство — эмулятор; физического телефона в этих измерениях нет.
