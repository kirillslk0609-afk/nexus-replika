# Реплика 0.6.1 — проверка без интернета на эмуляторе

**Стенд:** Android 15 ARM64, AVD с профилем Pixel 6, выделено 4096 МиБ RAM, 4 виртуальных CPU. Системное имя — `Android SDK built for arm64`. Это программный эмулятор на Mac, а не проверенный физический Google Pixel 6. Профиль не воспроизводит скорость процессора реального телефона.

`replica-offline-check-emulator.mp4` — непрерывная запись экрана длительностью 150,64 секунды, 1080 × 2400, без ускорения, монтажа и аудиодорожки. Запись сделана 7 ноября 2026 года. Модели были извлечены до записи. Приложение запустило реальную обработку выбранного аудио; готовый результат перед запуском не подставлялся.

Показаны выбор `replica-demo.wav` через системный диалог, английский язык, распознавание, пунктуация, два говорящих и четыре реплики, нажатие воспроизведения фрагмента, экспорт через системный диалог и окно «О записи». В начале системный диалог уже отфильтрован по имени тестового файла. Звук воспроизведения не записан.

Во время обработки включён авиарежим, Wi-Fi и мобильные данные отключены; `dumpsys connectivity` показывает `Active default network: none`. Реальные параметры сохранены в `device.json` и `offline-check.txt`.

Результат прогона:

- Длительность тестового аудио: 16,000 с.
- Обработка: 27,706 с, RTF ≈ 1,73. Это один UI-прогон одновременно с записью экрана, не сравнительный тест производительности.
- Найдены 2 говорящих, 4 реплики; 4 вызова локальной LLM.
- `export.json` после разбора полностью совпадает с `internal-result.json.result` и прежним демонстрационным эталоном.
- Ошибки распознавания сохранены; совпадение JSON не означает безошибочную расшифровку или полноценную оценку DER.
- Исходные пользовательские аудио и результат восстановлены после демонстрации байт в байт. Код приложения и APK не изменялись.

`verification.json` содержит проверки и SHA-256 видео и входного аудио. `video-verification.json` — технические параметры MP4. `frame-*.png` и `video-frame.png` декодированы из видео; `result.png` снят с экрана после обработки.

Корректная подпись для отчёта: **«Android 15 ARM64, эмулятор с профилем Pixel 6, 4 ГБ RAM»**. Проверка на физическом телефоне не проводилась.
