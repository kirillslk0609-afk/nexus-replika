# Демонстрация версии 0.2.0 на эмуляторе

`neuroscribe-emulator-demo.mp4` — непрерывная запись реального приложения, Android 15 ARM64 на Mac, авиарежим. Без ускорения, монтажных подмен и заранее подготовленного результата. Запись экрана без аудиодорожки.

Показаны выбор локального WAV, английский язык, запуск обработки, два голоса/четыре реплики, нажатие прослушивания фрагмента и экспорт JSON через системный диалог. `export.json` после разбора JSON совпадает с `internal-result.json.result`. `result.png` — экран, `video-frame.png` — извлечённый из MP4 кадр.

Это не видео физического телефона. Уточните, достаточно ли его для подачи; перед финальной защитой повторите сценарий на телефоне.

Текущий прогон: 16 секунд аудио, 3,983 секунды обработки, 2 говорящих, 4 реплики и 4 вызова LLM. Это обычный запуск через UI после подготовки моделей; не сравнивать напрямую со временем инструментального прогона. Длительность видео — 82,06 с.
