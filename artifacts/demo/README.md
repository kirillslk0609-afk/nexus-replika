# Демонстрация Реплики 0.5.0 на эмуляторе

`neuroscribe-emulator-demo.mp4` — непрерывная запись реального приложения Android 15 ARM64, авиарежим. Без ускорения, монтажа и подмены результата. Видео начинается в системном выборе файлов с заранее введённым поиском тестового файла; обработка запускается после его выбора. Запись экрана без аудиодорожки.

Показаны выбор локального WAV, английский язык, запуск обработки, два говорящих / четыре реплики, нажатие прослушивания, экспорт JSON через системный диалог и окно «О записи». Модели уже подготовлены до записи видео; это не проверка первого запуска с нуля.

`export.json` совпадает после разбора JSON с `internal-result.json.result` и эталонным результатом 0.4. Пунктуация, слова и времена не редактировались. Аудио: 16.00 с; обработка в этом UI-запуске: 17.179 с. Эти цифры не являются парным замером ускорения.

`result.png` — экран приложения, `video-frame.png` — кадр, декодированный непосредственно из MP4; сведения о длительности находятся в `video-verification.txt`. Историческое видео 0.2 сохранено в `v02/`.

Это не видео физического телефона. Перед сдачей следует проверить приложение на телефоне и согласовать допустимость демонстрации из эмулятора.
